# A-Sporting-Chance-for-All

The website is an advocacy site that promotes equality in sports. It serves as a digital poster that showcases support for fair treatment and equal opportunities for all athletes, regardless of their gender, race, ethnicity, or ability.

## Browser MIDI Synth

This project now also includes a simple browser-based synth (VST-style experience) powered by the Web Audio API.

### Features
- Upload `.mid` / `.midi` files.
- Parse MIDI note and tempo events in the browser.
- Play MIDI with selectable waveform (`sine`, `square`, `sawtooth`, `triangle`).
- Adjust attack, release, and master volume.
- Start/stop playback from the UI.

### How to use
1. Open `index.html` in a modern browser.
2. Click **Start Audio Engine** (required by browser audio policies).
3. Upload a MIDI file.
4. Click **Play MIDI**.
